## Height Agent V1.0
This Agent application is built based on some open-source projects, with reference to parts of the DeepSeek Harness source code and parts of the Codex architecture, and incorporates our team's original HAA (Hierarchical Anchor Mechanism). It is designed specifically for long tasks.

We have made original algorithmic improvements to address common Agent issues such as workspace overflow and search bugs, including but not limited to GEO manipulation, low-quality AIGC, and SEO cheating. We have also optimized weak models at the external algorithm level.

Our framework supports API Keys from 25 vendors, as well as locally deployed and pre-trained models. You only need to paste an API Key or drag model files into our parsing pool, and the algorithm will parse files such as GGUF on its own and proactively adapt special optimization algorithms.

By adding prefix/suffix units and related algorithms, we increase the cache hit rate without changing the input content, saving you more money.

To make it easier for you to use this product, please deploy Node 18+ and Python 3.10+ environments on the device where you need to use this product.
